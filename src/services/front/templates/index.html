Welcome

This app lets you register models, configure parameter sweeps, and run & monitor simulations.

Register Model

Upload a .zip, name your model, and define its I/O parameters using plain Python types.

  • Allowed types: str, int, float, bool
  • Inputs saved to input_parameters.json
  • Outputs saved to output_parameters.json
Go to Register
Run Simulation

Pick a model from the dropdown (loaded from your models directory). The page reads input_parameters.json and builds an editable grid:

  • int/float: name, min, max, step
  • str/bool: name, list of values (comma-separated)
Go to Run
Monitor

Track job status, logs, and results after starting a simulation.

Go to Monitor
Quick Start
  1. Register a model: upload the .zip, define input/output parameters.
  2. Run a simulation: choose the model, fill the parameter grid, and submit.
  3. Monitor progress and retrieve results.
Parameter Conventions
  • Types: str, int, float, bool (no tuples/custom types).
  • Numeric (int/float): provide min, max, step.
  • Discrete (str/bool): provide a comma-separated list of values. For booleans, use true,false or True,False.
Model Files

Each model folder typically contains:

<MODELS_DIR>/
  <model_name>/
    model.zip
    input_parameters.json
    output_parameters.json

The Run page scans <MODELS_DIR> to build the model list. Flash messages appear as Bootstrap alerts after actions.
